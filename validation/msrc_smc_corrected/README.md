# Corrected neutral SMC′ audit artifacts

Compact tables and plots from the corrected validation run described in
`docs/msrc_smc_validation.md`. The full chromosome-level genealogy and
waiting-distance tables were generated in a temporary directory and are not
included here. Regenerate them with the commands in the documentation.

The demo figure is the repository's four-taxon map comparison, showing local
topologies, genealogy change positions, recombination rates, and topology
autocorrelation for constant maps and a region of suppressed recombination.
