# Chromosome-scale MSRC-ARG benchmark

Measured results and limitations: [scientific report](../../docs/MSRC_ARG_10MB_SCALABILITY.md).
Run from the repository root with the project's installed Python environment.
Use a new output directory; checkpoints reject changed inputs. The full matrix
includes resource-limited failures and can take many minutes. No failed chromosome
is replaced. Extended/fresh runs replay the original seeds, not new replicates.

```bash
python validation/chromosome_scalability/benchmark.py --config validation/chromosome_scalability/benchmark.json --output /tmp/msrc-scale/main --suite all
python validation/chromosome_scalability/extended.py --benchmarks /tmp/msrc-scale/main --output /tmp/msrc-scale/extended --seconds 300
python validation/chromosome_scalability/fresh.py --benchmarks /tmp/msrc-scale/main --cached-extended /tmp/msrc-scale/extended --output /tmp/msrc-scale/fresh --seconds 300
python validation/chromosome_scalability/theory_check.py --theory-source /path/to/msrc-paper --config validation/chromosome_scalability/benchmark.json --output /tmp/msrc-scale/theory.json
python validation/chromosome_scalability/analysis.py --benchmarks /tmp/msrc-scale/main /tmp/msrc-scale/extended /tmp/msrc-scale/fresh --theory-check /tmp/msrc-scale/theory.json --output /tmp/msrc-scale/analysis
python validation/chromosome_scalability/audit_exports.py --benchmarks /tmp/msrc-scale/main /tmp/msrc-scale/extended /tmp/msrc-scale/fresh --output /tmp/msrc-scale/export_audit.json
python validation/chromosome_scalability/regression.py --history /tmp/msrc-scale/main/histories/n4_s101.pkl --output /tmp/msrc-scale/regression.json
MSRC_THEORY_SOURCE=/path/to/msrc-paper python -m pytest -o addopts='' -q -p no:cacheprovider
```

One self-contained 10-Mb example (inline shared Moran history):

```bash
python validation/chromosome_scalability/worker.py --job validation/chromosome_scalability/results/analysis/examples/MSRC_ARG/input.json --output /tmp/msrc-10Mb-example
```

The worker uses the production ARG API, not a separate simulation kernel.
`--suite primary` runs the four-taxon length series; `multi`, `replicates`, and
`sensitivity` add larger taxon counts, seeds, and rate/kappa settings. Histories
and ARG events use independent SeedSequence children `[seed, taxa, 0]` and
`[seed, taxa, 1]`. Settings with the same seed intentionally share histories.
No survival conditioning or failed-trajectory rejection is used.

## Archive

`results/analysis/benchmark_metrics.csv` contains all 67 dataset attempts,
including limits and blocked histories. Six history-generation/cache jobs are
separately preserved under `results/measured/history_*`. Per-case summaries,
inputs, sampled carrier/segment traces, heartbeats, provenance, source hashes,
and library versions are included. Missing completed-run measurements remain
blank, with partial progress in separate fields. Trace snapshots can occur
mid-event; sampled candidate-option counts are not complete rate-table sizes.
Completed peak-carrier/segment counts come from the production result.

`results/analysis/` contains four PNG/SVG figures, per-chromosome/window data,
selected-position estimates, censoring-aware tract data and three 10-Mb example
tree sequences/coordinate-indexed Newick files. `examples_30taxon/` contains
completed **neutral** controls. Only one MSRC example event log is archived;
large pickle histories and other raw event/tree files are regenerated by the
commands above. Archived absolute temporary paths are provenance, not portable
inputs. Use the example `input.json` or the benchmark driver for replay.
Cached histories are trusted local pickle files; do not load untrusted pickles.

Examples declare generations as tree-sequence time units. Some early raw
measurements predate this additive metadata correction and say `unknown`;
`export_audit.json` records this explicitly. Archived example copies annotate
generations without changing any node times. File sizes in benchmark tables
are the actual raw sizes measured at the time. The scientific cache-vs-inline
regression compares event/Newick/marginal CSV files, not binary metadata bytes.

The exact Moran target at M=2000 currently raises a numerical overflow; the
neutral MSC line in the figures is explicitly a neutral control, not an MSRC
substitute. Three chromosomes give descriptive variability, not tight marginal
equivalence evidence. Phase 8 population-genetic statistics are deferred.
